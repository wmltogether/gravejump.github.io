# 验证记录

当前版本：坟头蹦迪 / GRAVE JUMP。Node.js 24、严格 TypeScript、PixiJS 8，全部美术为 SVG。

## 自动验证

`npm run check` 包含严格类型检查、72 项测试、干净构建和产物资源验证。

- 固定步长、30/60/120/144 Hz 一致性，逐帧按键边沿、缓冲与土狼时间。
- 单向平台、快速斜向落地、相对运动连续碰撞、角色轮廓与朝向、受伤保护、五心生命、坠落与重置。
- 黄瓜恢复一心、满血消耗、拾取去重，不修改受伤保护时长。
- 三秒火箭加速、免疫空中及企鹅石头、到期恢复重力与伤害、操控、暂停、刷新、跨层进度。
- 企鹅投石、单心伤害、下落踩踏与弹起、斜擦及上升不误杀、同帧踩踏优先。
- 键盘重复、多触点与画布左右半屏、释放取消、失焦和后台暂停、右键/滚动抑制。
- 600 帧持续长按、跨中线切换、画布外释放与捕获失败、系统选字/长按/拖拽/缩放拦截、暂停菜单触摸保留，以及旧版 Touch Events 多指和取消。
- 五心 UI、保护与危急状态、恢复与失去动画、重开清理、透明 glitch 强度和覆盖范围。
- 实际 Pixi Sprite 的脚底锚点与不同贴图分辨率；前景/效果层次。
- iPhone 可见区域、HUD、安全区、整张游戏卡片尺寸、相机随视口变化保持玩家可见。
- HTML/SVG ID 与引用、角色 SVG 尺寸、资源完整性、过时产物清理、项目子路径部署。

平台路线测试隔离火箭与企鹅，只测基础路线可达性；新玩法由独立测试覆盖。Node 中的 Pixi 变换测试不等于显卡运行或真机触屏验证。

## 实机边界

此前本地预览地址被已保存的网站权限或管理策略拒绝；未更换端口或通道绕过。因此实际 WebGL、手机触屏、Safari 地址栏交互、音效和视觉观感仍未记录为通过。CI 成功只证明自动检查及静态部署成功。

## 人工验收清单

- 打开 Pages 的项目子路径，资源完整加载，直接开始游戏。
- 桌面和 iPhone 竖屏：场景等比完整显示，角色、五心和按钮可见；地址栏和旋转不裁切角色。
- 键盘及左右半屏、多指、失焦暂停与重开输入清理。
- 手机左右半屏分别长按 10 秒：角色持续移动且不弹选字或长按菜单；跨中线、松手、系统取消与切后台后无卡键；暂停菜单仍可点击。
- 白边落石清晰，受伤故障条半透明且可见，不遮挡玩法；开启减少动态效果后关闭故障条。
- 黄瓜回血且满血消耗；火箭三秒冲刺与免疫、结束后的操控和落地。
- 企鹅投石扣一心、从上方踩中击败，斜擦不误判；音乐每十层累积解锁。
- 帮助、暂停、音效开关、最高纪录与隐私模式下的存储兼容。
